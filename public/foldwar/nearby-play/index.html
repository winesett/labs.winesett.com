Both players need Fold War on their own device, with Wi-Fi enabled and Local Network access allowed.

Before you begin.

This guide is for two nearby devices running the same Fold War version. Keep both apps open and choose the same game: Naval Duel or tic-tac-toe.

Local Network permission lets the devices discover and connect to each other. There’s no account, developer-operated game server, or remote matchmaking.

Host on the first device.

  1. Open the game and tap Host game.
  2. Allow Local Network access when prompted.
  3. Keep the lobby open. Share its temporary host name and six-digit pairing code with the other player.

Join on the second device.

  1. Open the same game and tap Join game. Allow Local Network access.
  2. Select the first device’s host name under Nearby games.
  3. Enter the six-digit code shown by that host, then tap Connect.
The step that matters

Select the host as well as entering the code. The code belongs to that hosting session. If you start again, use the newly displayed code.

Take the first turn.

In tic-tac-toe, the host is X and plays first. In Naval Duel, choose your fleet arrangements and both tap Ready; the host fires first.

Each device adapts its own layout. Compact unfolded screens use Phone, while an active fold selects Tabletop on supported iPhone Duo systems. After the match, both players tap Play again for a rematch.

If the host is missing.

  • Check that both devices have the same game open and that the first device is still hosting.
  • Keep Wi-Fi on and check Local Network access for Fold War on both devices.
  • Tap Refresh on the joining device, select the host, and use its current code.
  • If you leave to change permissions in Settings, return and start a fresh Host/Join session.

Keep Fold War in the foreground throughout the match. Leaving a game or switching apps ends the session; it does not resume when you come back. Get more connection help →

No rival handy?

Choose either game and tap Vs computer. Solo play uses one device, works offline, and does not need Local Network permission.
